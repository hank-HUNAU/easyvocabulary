# 词书架 · 词汇 1000 / 2000 / 4000

面向平板和笔记本的离线词汇学习 PWA。应用把 14 册教材拆成单元，以「音形对应 → 词卡 → 听写 → 句中填空 → 句子翻译」五步学习链组织练习，并使用间隔重复安排复习。

## 在线使用

https://hank-hunau.github.io/easyvocabulary/

## 内容

- 词汇 1000：4 册，960 词
- 词汇 2000：4 册，1,600 词
- 词汇 4000：6 册，3,600 词
- 共 6,160 词、12,320 个英音/美音音频

## 特点

- 原生 HTML / CSS / JavaScript，无构建步骤、无后端
- PWA 离线使用，学习进度保存在浏览器 `localStorage`
- 14 册数据按需加载，音频首次播放后缓存
- 四级评分与几何递增复习间隔
- 明亮 / 暗色主题、键盘快捷键和平板/笔记本响应式布局
- 自动迁移旧版 `anki_*_state` 学习进度

## 本地运行

在项目根目录启动任意静态文件服务器：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。不要直接双击 `index.html`，音频、JSON 数据和 Service Worker 需要通过 HTTP 加载。

线上站点由 GitHub Pages 从 `main` 分支根目录发布。推送后等待页面构建完成，再访问上方在线地址。
